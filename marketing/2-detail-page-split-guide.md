# 쿠팡 상세페이지 이미지 30,000px 제한, 이렇게 해결하세요 (무료 도구)

쿠팡에 상세페이지 이미지 올리다가 이런 에러 본 적 있으신가요?

> **"이미지 세로 크기가 최대 30,000픽셀을 초과합니다"**

기획자가 정성 들여 만든 세로 4만~5만 픽셀짜리 상세페이지가 업로드 자체가 안 됩니다. 그렇다고 포토샵에서 일일이 자르자니 시간이 오래 걸리고, 자르는 위치도 어색해집니다.

이 문제 해결하는 무료 도구를 만들었습니다.

👉 **[상세페이지 이미지 자동 분할 도구](https://seller-image-tool.vercel.app/split)**

## 왜 이런 제한이 있을까

주요 플랫폼의 세로 이미지 제한을 보면:

| 플랫폼 | 상세페이지 최대 세로 |
|---|---|
| 쿠팡 | 30,000px |
| 네이버 스마트스토어 | 이미지 파일당 20MB (실질적으로 세로 제한) |
| 11번가 | 상세페이지 이미지 개별 관리 |
| 무신사 | 이미지당 세로 제한 있음 (파트너센터 확인) |

브라우저 렌더링 성능과 페이지 로딩 속도를 위한 제한입니다. 세로 5만 픽셀 이미지 하나를 다운로드하는 것보다, 3천 픽셀짜리 이미지 10개로 나누는 게 스크롤 UX와 캐시 관리 모두 유리합니다.

## 해결법 3가지

### 1. 포토샵/피그마에서 수동으로 자르기
- 정확한 위치에서 자를 수 있음
- **단점**: 상품 수십 개 상세페이지 처리하면 하루 종일 걸림

### 2. 유료 툴/플러그인 구매
- 자동화 가능
- **단점**: 월 몇 만원~ 비용, 기획자/셀러 모두 배워야 함

### 3. 브라우저에서 무료로 자동 분할 ★ 추천
- 상세페이지 이미지를 드래그 → 최대 세로 높이 선택 → 분할
- **10초 만에** 여러 조각으로 자동 분할
- ZIP으로 다운로드
- 브라우저에서만 처리되므로 이미지 유출 걱정 없음

## 무료 도구 사용법

1. **[상세페이지 이미지 자동 분할](https://seller-image-tool.vercel.app/split)** 접속
2. 긴 상세페이지 이미지를 드래그
3. **조각당 최대 세로 높이** 프리셋 선택:
   - 2,000px (모바일 안정)
   - **3,000px (표준·권장)**
   - 4,000px (긴 조각)
   - 5,000px (쿠팡 30,000px 대응 시 6조각으로 나뉨)
4. **출력 폭** 선택:
   - 원본 폭 유지
   - 780px (쿠팡 상세)
   - 860px (스마트스토어 상세)
   - 1000px
5. **"분할 시작"** → 결과 미리보기 → **"전체 ZIP 다운로드"**

파일명은 `상품명__part_01_of_08.jpg`, `상품명__part_02_of_08.jpg` 형식으로 자동 정렬됩니다.

## 여러 상품을 한 번에

여러 상품의 상세페이지를 동시에 업로드하면 상품별 폴더로 정리해서 ZIP으로 압축됩니다.

```
detail-split.zip
├── 상품A/
│   ├── 상품A__part_01_of_08.jpg
│   ├── 상품A__part_02_of_08.jpg
│   └── ...
├── 상품B/
│   ├── 상품B__part_01_of_06.jpg
│   └── ...
```

## 자주 묻는 질문

**Q. 이미지 품질이 떨어지지 않나요?**  
A. 원본 해상도를 유지한 채 분할하고, JPEG 품질도 50~100% 사이에서 조절 가능합니다. 기본값 90% 는 상세페이지에 충분합니다.

**Q. WebP 로 저장할 수 있나요?**  
A. JPEG / PNG / WebP 세 가지 포맷 지원합니다. 상세페이지에는 JPEG 가 호환성이 가장 좋습니다.

**Q. 이미지가 서버에 저장되나요?**  
A. 아니오. 모든 처리는 여러분 브라우저 안에서만 일어납니다. 상품 사진 유출 걱정 없습니다.

**Q. 무료인가요?**  
A. 완전 무료이며, 회원가입도 없습니다.
