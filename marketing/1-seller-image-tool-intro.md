# 스마트스토어, 쿠팡, 무신사 이미지 한 방에 만드는 무료 도구를 만들었습니다

온라인 셀러라면 다들 한 번쯤 이런 경험 있으실 겁니다.

같은 상품 이미지 하나 만들려고 포토샵 켜고,
- 스마트스토어용 **1000×1000 정사각**
- 쿠팡용 **500×500**
- 무신사용 **1000×1333 세로형**
- 인스타 광고용 **1080×1350 세로형**
- ... 이걸 상품 20개에 반복

하루가 그냥 사라집니다. 그것도 매번.

이 문제 하나 풀자고 무료 웹 도구를 하나 만들었습니다.

👉 **[셀러 이미지 변환기 바로가기](https://seller-image-tool.vercel.app)**

## 어떤 도구인가요

이커머스 셀러가 상품 이미지를 각 플랫폼 규격에 맞춰 **한 번에 변환**하는 웹 도구입니다.

### 지원 플랫폼 13개
- 네이버 스마트스토어
- 쿠팡
- 11번가
- 지마켓 · 옥션
- 무신사
- 카카오톡 스토어
- 인스타그램 (정사각/세로)
- 오늘의집
- 에이블리 · 지그재그
- SSG.com
- 롯데온
- 위메프

플랫폼별 규격이 자동으로 적용되고, 원하는 조합을 골라서 한 번에 처리할 수 있습니다.

### 주요 기능
- **드래그앤드롭 업로드** — 여러 장 동시에
- **플랫폼별 규격 자동 리사이즈** — 흰색 여백 자동 채우기
- **AI 배경 제거** — 브라우저에서 바로 (베타)
- **워터마크** — 텍스트 + 로고 이미지 동시 삽입
- **상품코드 CSV 매핑** — 대량 상품의 파일명 자동 정리
- **상세페이지 이미지 자동 분할** — 쿠팡 30,000px 세로 제한 대응
- **프리셋 저장** — 자주 쓰는 조합 원클릭 로드
- **자동 저장** — 다음 방문에 그대로 복원

### 100% 브라우저에서 처리
가장 중요한 부분입니다. **상품 이미지가 서버로 절대 전송되지 않습니다.**

모든 이미지 처리는 여러분의 웹 브라우저 안에서 Canvas API와 WebAssembly로 이뤄집니다.

- 신상품 이미지 유출 걱정 없음
- 인터넷 없어도 (한 번 로드 후) 작동
- 처리 속도 빠름 (네트워크 왕복 없음)

## 사용법 (30초면 익숙해집니다)

1. 상품 이미지를 드래그하거나 클릭해서 업로드
2. 변환할 플랫폼 체크 (기본으로 스마트스토어 + 쿠팡 선택됨)
3. **"변환 시작"** 버튼 클릭
4. **"전체 ZIP 다운로드"** 로 플랫폼별 폴더로 정리된 파일 받기

끝입니다.

## 팁: 프리셋을 활용하세요

첫 방문 때 자주 쓰는 플랫폼 조합 + 브랜드 워터마크를 설정하고, **"현재 설정을 프리셋으로 저장"** 을 누르세요.

다음 방문부터는 프리셋 클릭 한 번이면 셋업이 끝납니다.

## 만든 이유

본인이 커머스 관련 백엔드 개발을 하다 보니, 셀러들이 이미지 편집에 얼마나 많은 시간을 쓰는지 옆에서 봤습니다.

포토샵 켤 필요도 없고, 회원가입도 없고, 결제도 없이 그냥 브라우저에서 바로 되는 도구가 있으면 좋겠다 싶어 만들었습니다.

**완전 무료**이고, 앞으로도 기본 기능은 무료로 유지할 계획입니다.
